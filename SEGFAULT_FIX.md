# Segmentation Fault Fix - PyQt5 Window Interaction

## Problem
Your program was experiencing segmentation faults when clicking or resizing windows generated by PyQt5. This happened because of unsafe interactions between matplotlib and PyQt5 event handling.

## Root Causes

### 1. **Unsafe Agent List Iteration During Click Events** ❌
**File:** `visualization.py` → `_on_click()` method

**Issue:** 
```python
for bacterium in self.model.agent_set:  # DANGEROUS!
    # Agents can be removed while iterating
```

The `agent_set` could be modified (agents removed) while the loop was still iterating, causing iterator corruption.

**Fix:**
```python
agents = list(self.model.agent_set)  # Create safe copy
for bacterium in agents:  # Safe iteration
```

### 2. **Improper Matplotlib Artist Removal** ❌
**File:** `visualization.py` → `_update_highlight()` method

**Issue:**
```python
self.highlight_scat.remove()  # Can fail if canvas state is bad
self.highlight_scat = self.ax.scatter(...)  # Recreate immediately
```

Repeatedly removing and recreating scatter plots during window resize events can corrupt matplotlib's internal state.

**Fix:**
- Try to update offsets first (safer) before attempting removal
- Wrap all remove() calls in try-except blocks
- Use `set_offsets()` instead of remove/recreate when possible

### 3. **Missing Error Handling in Canvas Drawing** ❌
**File:** `visualization.py` → `draw()` and `update_main_plot()` methods

**Issue:**
```python
self.fig.canvas.draw_idle()  # Can fail during window events
```

Canvas drawing can fail when the window is being resized or closed.

**Fix:**
- Added try-except wrapper around `draw_idle()`
- Added exception handling for all scatter plot updates
- Gracefully skip updates if agent_set is inaccessible

### 4. **Qt Event Processing Issues** ❌
**File:** `control_panel.py` → `update()` method

**Issue:**
```python
self.qt_app.processEvents()  # Can raise RuntimeError
```

Calling `processEvents()` while window is closing raises RuntimeError.

**Fix:**
- Distinguish between RuntimeError (window closing - benign) and other exceptions
- Better error messages

## Changes Made

### `visualization.py`

1. **`_on_click()` method:**
   - Added safe copy of agent_set before iteration
   - Added exception handling for agent_set access

2. **`update_main_plot()` method:**
   - Wrapped entire method in try-except
   - Added error handling for each scatter plot update
   - Added error handling for field updates
   - Graceful degradation if updates fail

3. **`_update_highlight()` method:**
   - Changed from remove/recreate to update-first approach
   - All remove() calls now wrapped in try-except
   - Better handling of marker changes

4. **`clear_highlight()` method:**
   - Added try-except around remove() call

5. **`draw()` method:**
   - Added canvas state check
   - Better error messages distinguishing critical vs non-critical errors

### `control_panel.py`

1. **`update()` method:**
   - Added RuntimeError-specific handling
   - Better error messages for debugging

## Why This Works

- **Safe Iteration:** Creating a list copy prevents iterator corruption
- **Graceful Degradation:** All matplotlib operations have error handling
- **Non-Blocking:** Errors in visualization don't crash the simulation
- **Qt Safety:** Better handling of Qt's event loop during window events
